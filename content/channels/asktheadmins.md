# #asktheadmins

> Direct communication channel with ZATech administrators.

**807 members** • **Created: July 1, 2016**

---

<details open>
<summary><strong>Purpose</strong></summary>

A dedicated channel for South African tech community members to ask questions, raise concerns, or communicate directly with the ZATech admin team. Whether you need help with community guidelines, want to request an announcement in the main announcements channel, report an issue, or suggest improvements to the community, this is where you can reach the administrators. Please post individual, shareable messages for transparency and community benefit.
