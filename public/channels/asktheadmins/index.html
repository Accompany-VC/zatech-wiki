#asktheadmins

This channel is for asking questions to the ZATech administrators.

Reporting

If you are being harassed by a member of ZATech, notice that someone else is being harassed, or have any other concerns, this is the place to report it. For more information, please see the Code of Conduct.

There are a few ways to report an issue. Please choose the one you are most comfortable with. They are listed from most public to most private.

Use the “Report an Issue” workflow

You can use the “Report an Issue” workflow directly in the #asktheadmins channel. This is the most public way to report an issue, but it is fast and effective.

Create a private channel with the admins

For a more private way to report an issue, you can create a private channel and invite the admin team.

  1. Create a private channel called admins-$YOUR_USERNAME, for example admins-cdanvers.
  2. Invite the admin team to your new private channel by typing /invite @adminteam.

DM an administrator

For the most private method, you can send a direct message to any of the administrators. You can see a list of current administrators here.

Administrators will respond as soon as they are able. If the person who is harassing you is on the admin team, they will recuse themselves from handling your incident.

We will take all good-faith reports of harassment by ZATech members, especially the administrators, seriously. This includes harassment outside our spaces and harassment that took place at any point in time.

You can see a list of current administrators here.
